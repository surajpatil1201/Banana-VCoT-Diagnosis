# Banana-VCoT-Diagnosis
Lightweight Explainable Banana Leaf Disease Diagnosis on Real-Field Imagery: A Visual Chain-of-Thought Framework with Vision–Language Models
Methodology-
We assembled BananaLeaf-Field-3K, a 3,023-image real-field banana-leaf dataset (CMV: 1,048; Healthy: 938; Sigatoka: 1,037) collected directly from agricultural plots, capturing the natural distribution of lighting, framing, occlusion, and leaf-orientation variability that field AI tools must contend with in practice. The dataset was stratified into a 70 / 15 / 15 train / validation / test partition (seed = 42) with class proportions preserved within each split. Three diagnostic frameworks of increasing domain-adaptation intensity were evaluated on this identical partition. Phase 1 quantifies the zero-shot capability of LLaVA-1.5-7B across five carefully designed prompt strategies. Phase 2 adapts the same vision–language model via parameter-efficient Low-Rank Adaptation (LoRA) attached to all linear projections of the language transformer plus a lightweight classification head, training only 0.60% of the 7.106-billion model parameters. Phase 3 introduces a Visual Chain-of-Thought (VCoT) framework in which a compact 4.01-million-parameter EfficientNet-B0 classifier emits the diagnosis and a Grad-CAM saliency map (the “visual thought”), and a frozen LLaVA-1.5-7B is conditioned on the saliency overlay together with the predicted class to produce an open-ended, evidence-grounded symptom description (the “verbal thought”). All experiments were run on a single NVIDIA A100 (40 GB) GPU; the EfficientNet branch is small enough to run on consumer mobile hardware.
